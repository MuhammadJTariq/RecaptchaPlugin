# RecaptchaPlugin
This is a basic Recaptcha Plugin for WordPress enhancing WordPress login Security and Preventing Malicious Bots

#Usage of Plugin
To use this plugin download the Zip File go to WordPress -> plugin -> add new plugin -> upload plugin -> upload the zip file

#configuration
Go to Google Recaptcha V2 - because this plugin is only compatible with V2 - add your website domain.
Copy your Site Key and Secret Key -> go to wordpress admin -> Recaptcha Settings and paste your site key and secret key
// Your Secret key is encrypted using the AES-256-CBC method to prevent users from getting it and encrypting it
Once that's done - You're good to go 

Go to the WordPress Login Page and you have just added extra security to your page.
